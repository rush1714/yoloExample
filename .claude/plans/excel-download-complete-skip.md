# Excel 图片全部下载时跳过导入

## 目标

在 `scripts/data_import/import_images_from_excel.py` 中增加下载前完成度判断：Excel 的目标列解析出的每条有效、去重 URL 若都已有对应的本地图片文件，则不创建下载线程、不发起网络请求，直接退出。

## 实施

1. 新增按 `row_number` 与 URL 附件 stem 生成的本地文件前缀查找逻辑，兼容实际下载后由响应 Content-Type 决定的图片扩展名。
2. 在读取 Excel 记录和创建输出目录后，统计每条记录是否存在对应图片文件；只有全部匹配时构建 `skipped` 结果、写入下载报告并输出“全部已完成”的汇总后退出。
3. 保留现有 `download_one` 中的存在即跳过逻辑，处理部分已下载、扩展名无法在请求前确定和并发竞态等情况。
4. 新增单元测试覆盖：全部已下载时无需调用下载函数、部分已下载时仍返回未完成记录、同一行多 URL 的前缀不会误匹配。
5. 更新 README、设计文档与当日报告，运行单元测试、脚本编译、Makefile 干跑和 `git diff --check`。
