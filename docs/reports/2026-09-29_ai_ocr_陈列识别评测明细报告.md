# ai-ocr / 多模态大模型陈列识别实测明细导出报告

## 一、 实测汇总指标 (Summary Metrics)

- **评测模型**：多模态视觉大模型 (`Gemini-Vision / Qwen-VL` 通过 ai-exchange / 本地网关调用)
- **应识别目标总数 (Ground Truth)**：`43` 件 (全量 350 张样本包含 521 件目标)
- **实际识别总数 (Predictions)**：`50` 件 (存在明显多报假目标)
- **① 应识别且已识别 (True Positives / TP)**：`39` 件
- **② 应识别未识别 (False Negatives / 漏检 FN)**：`4` 件 (漏检率 <10%)
- **③ 不应识别却识别 (False Positives / 误检 FP)**：`11` 件 (误检率高达 22%)
- **精确度 (Precision)**：**78.00%** (相比自研 YOLO 的 96.10% 低 18 个百分点)
- **召回率 (Recall)**：**90.70%**
- **综合 F1 得分**：**83.87%**
- **单图平均响应耗时**：**9.73 秒** (相比 YOLO 的 20~30 毫秒慢约 300 倍)
