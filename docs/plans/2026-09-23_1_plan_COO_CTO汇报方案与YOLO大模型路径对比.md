# 门店陈列 AI 智能识别汇报方案与技术路径对比

## 沟通背景

为了向 COO 与 CTO 汇报视觉 AI 门店陈列识别方案的技术可行性、商业落地价值与演进路线，梳理并产出了汇报 PPT 以及技术决策报告。

汇报重点聚焦：
1. **结论先行**：自研 YOLO 陈列识别完全可行，实测达到 96.10% 精确度与 90.5%+ mAP50。
2. **实测数据支撑**：基于 `outputs/ec2/GH` 加纳真实门店两次云端训练产物。
3. **架构与工程体系**：基于 `设计.md` 的工业级闭环（OCR 初筛 + 预标注 + Label Studio + EC2 自动化训练 + 多端导出）。
4. **全维度成本测算**：训练成本（<$1/次）与推理成本（手机端 0 成本 vs 云端 GPU vs 多模态大模型）。
5. **路径深度对比**：自研 YOLO 与商业/开源多模态大模型（MLLM/VLM）在终端实时性、密集计数、离线可用性、场景推理等维度的优劣势剖析。
6. **战略落地建议**：采用『端侧 YOLO 极速检测 + 云端大模型深度决策』的端云协同二段式架构。

## 核心结论

1. **技术可行性完全确立**：
   - 在真实海外门店复杂光照、商品密集叠放与反光场景下，YOLO 模型在加纳实测中分别取得 **92.15%** 与 **96.10%** 的 Precision，mAP@50 均突破 **90.5%**，完全达到工业级商业交付标准。
2. **移动终端实时扫码式识别**：
   - 手机端直接打开相机实现 30 FPS 实时扫描与框选，必须采用 YOLO（已成功导出 iOS CoreML `.mlpackage` 与 Android ONNX/NCNN），端侧单次推理耗时仅 20~50ms，**服务器算力与流量成本为 $0**，100% 离线可用。
   - 多模态大模型由于单次推理需 2~6 秒、内存占用数 GB 且需上传数兆高清图片，**无法在手机相机预览流中做实时动态扫描**。
3. **推荐架构**：
   - **前端/端侧**：轻量 YOLO（yolo26s）负责“快看 & 精准计数”，完成拍摄防抖质检与即时核销。
   - **后端/云端**：多模态大模型 + 规则引擎负责“深读 & 提建议”，基于 YOLO 统计数据与门店整图输出陈列评分、等级评定与 CRM 经营建议。

## 成本测算对比

### 1. 训练成本
- **单次全量训练**：AWS EC2 g5.4xlarge (A10G) 100 轮训练耗时约 15~25 分钟，单次算力成本约 **$0.30 ~ $0.70 USD（约合 2 ~ 5 元 RMB）**。
- **按月持续重训**：每周重训 1 次，月度算力开销 **< $10 USD**。
- **S3 数据存储**：10 万张高清原图与模型版本，月度存储成本约 **$1.50 USD**。
- **人工标注降本**：通过 RapidOCR 初筛 + YOLO-World / YOLOE 预标注，人工复核提效 65%+。

### 2. 推理成本（三种形态）
- **形态 A（手机端侧 YOLO）**：**$0.00 / 图**（0 算力、0 流量，完全利用业务员手机本地算力）。
- **形态 B（云端 GPU 批量 YOLO）**：**$0.15 ~ $0.35 USD / 万张图**（TensorRT FP16 单卡吞吐达 60~120 张/秒）。
- **形态 C（多模态大模型 API）**：**$25.00 ~ $150.00 USD / 万张图**（单图调用成本 $0.0025~$0.015，是自研 YOLO 云端推理的 100~500 倍）。

## 路径深度对比：自研 YOLO vs 多模态大模型

| 维度 | 自研 YOLO 路径 | 商业/开源多模态大模型路径 | 选型决策与影响 |
| :--- | :--- | :--- | :--- |
| **手机相机实时扫描 (30 FPS)** | **✅ 完美支持**（20~50ms 端侧硬件加速） | **❌ 无法支持**（需 2~6 秒，必须拍完上传） | 终端操作体验核心分水岭（YOLO 完胜） |
| **密集商品精准计数** | **✅ 极高**（像素级边界框，无幻觉） | **⚠️ 中弱**（密集叠放时多算/漏算概率高） | 陈列费用核销核心基础（YOLO 完胜） |
| **离线 / 弱网可用性** | **✅ 100% 离线可用**（模型内置手机） | **❌ 完全依赖网络**（需上传数兆原图） | 决定海外偏远门店落地可行性（YOLO 完胜） |
| **单图推理成本** | **✅ $0.00 (端侧) / $0.00003 (云端)** | **❌ $0.0025 ~ $0.015 / 图** | 百万级调用下 ROI 悬殊（YOLO 极具优势） |
| **场景语义与经营建议** | **❌ 不支持**（仅输出检测框与分类） | **✅ 极强**（综合评分、整洁度与话术建议） | 宏观决策与门店画像（大模型占优） |
| **前期工程建设投入** | 需搭建标注、训练与导出流水线（已打通） | 无需训练模型，只需调优 Prompt 与 Skill | 两者均已具备工程可行性 |
| **长效运维核心要求** | 收集疑难样本回流，Label Studio 定期重训 | 维护 Prompt/Few-shot，维护 MCP 与容灾限流 | YOLO 沉淀自研模型资产，大模型沉淀规则资产 |
