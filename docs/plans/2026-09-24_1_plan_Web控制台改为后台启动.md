# 2026-09-24 Web 控制台改为后台启动计划

## 背景与目标

当前 `make web-console` 命令直接在前台运行 `node web-console/server.js`，会占用当前终端窗口，且缺少进程管理与停止命令。
参考 Label Studio 的 `ls-start` 与 `ls-stop` 设计，将 `make web-console` 改造为**后台守护进程启动**，记录 PID 和日志，并补充 `web-console-stop` 停止命令，同时支持通过 `WEB_CONSOLE_PORT` 自定义端口。

## 涉及修改清单

1. **`makefiles/common/Makefile.mk`**
   - 增加公共参数：
     - `WEB_CONSOLE_PORT ?= 3000`
     - `WEB_CONSOLE_LOG_FILE ?= $(LOG_DIR)/web-console.log`
     - `WEB_CONSOLE_PID_FILE ?= $(LOG_DIR)/web-console.pid`
   - 将 `web-console` 改造为后台启动：
     - 依赖 `prepare-dirs` 确保日志目录 `logs/` 存在。
     - 端口探测：若 `WEB_CONSOLE_PORT` 已有运行进程，则提示 PID 与日志路径，避免重复启动。
     - 后台启动：`( PORT=$(WEB_CONSOLE_PORT) node web-console/server.js ) >> $(WEB_CONSOLE_LOG_FILE) 2>&1 &`。
     - PID 保存与进程存活检查（`kill -0 $$pid`），启动成功打印访问地址 `http://localhost:$(WEB_CONSOLE_PORT)` 与日志路径。
   - 新增 `web-console-stop` 目标：
     - 查找端口 `$(WEB_CONSOLE_PORT)` 对应的进程并安全停止，清理 PID 文件。
   - 在 `.PHONY` 和 `help-params` 中补充 `web-console`、`web-console-stop` 及相关参数说明。

2. **文档更新**
   - `makefiles/common/README.md`：更新 `web-console` 说明并新增 `web-console-stop`。
   - `README.md`：说明 `make web-console` 支持后台运行与停止。
   - `设计.md`：同步更新本地流程控制台运行机制。

3. **测试验证**
   - 运行项目全量单元测试 (`.venv/bin/python -m unittest discover tests`，87 个测试用例全部通过)。
   - 验证 `make web-console`、`make web-console-stop`、`make help`、`make help-params` 语法及实际启停行为均符合预期。
