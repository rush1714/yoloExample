# YOLO26M 纸尿裤大类训练报告计划

## 背景

为 EC2 训练产物 `outputs/ec2/diaper_category/CI/v2026-08-28/improve` 生成可追溯的训练评估报告。该次训练使用 `yolo26m.pt`，任务为单类别纸尿裤检测。

## 已确认事实

- 训练配置：`imgsz=960`、`epochs=100`、`batch=-1`、GPU `device=0`。
- 数据集：训练集 585 张、验证集 168 张、测试集 84 张，总计 837 张。
- 最优验证结果出现在第 82 个 epoch：Precision 0.7517、Recall 0.7131、mAP50 0.7399、mAP50-95 0.3713。
- 已归档 `best.pt`、`last.pt`、CSV 指标、训练参数及训练/验证可视化图。

## 执行计划

1. 基于 `metrics/results.csv`、`metrics/args.yaml`、`evaluation-summary.md` 与已有可视化产物，核对训练配置、数据规模和最佳 epoch。
2. 计算训练总时长、单 epoch 平均耗时，并分析指标曲线中最佳点、最终点和收敛趋势。
3. 生成中文 Markdown 训练报告，包含：训练背景与配置、数据集划分、核心指标、曲线解读、产物清单、当前结论、限制与下一轮改进建议。
4. 将报告写入 `docs/reports/`，并在本计划中追加实际执行结果与报告路径，确保后续可追溯。

## 验收标准

- 报告中的数值可回溯至本次训练产物。
- 明确区分验证集指标与尚未执行的独立测试集评估。
- 包含可执行的数据和训练改进方向，不将当前结果误表述为可直接生产上线。

## 执行结果

- 已生成正式报告：`docs/reports/2026-08-31-diaper-category-CI-v2026-08-28-yolo26m训练报告.md`。
- 已核对 100 个 epoch 的原始 CSV 指标。主检查点为第 82 轮的 `best.pt`：Precision 0.7517、Recall 0.7131、mAP50 0.7399、mAP50-95 0.3713。
- 第 87 轮达到 F1 与 mAP50 峰值，但 mAP50-95 低于第 82 轮；因此保留第 82 轮作为当前推荐权重的选择合理。
- 总训练耗时 3,098.14 秒（约 51 分 38 秒），第 82 轮以后指标进入平台期。报告已明确验证集与尚未完成的独立测试集评估边界，并列出错误样例闭环、标注复查和 test 集验证等后续动作。
