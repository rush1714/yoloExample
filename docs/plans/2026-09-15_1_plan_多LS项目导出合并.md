# 多个 Label Studio 项目导出并合并有效标注计划

## 背景

用户希望把多个 Label Studio 项目（例如 `21,20`）中的好标注数据导出并合并，形成一个可继续转换为 YOLO 训练集的合并 JSON。命令形式希望类似：

```bash
make diaper-merge-ls-projects \
  DIAPER_COUNTRY=GH \
  DIAPER_VERSION=v2026-09-15 \
  DIAPER_LABEL_NAME=diaper \
  LS_PROJECT_IDS=21,20
```

核心要求：

- 支持多个项目 ID。
- 自动逐个导出 Label Studio JSON。
- 只合并“有有效框”的任务。
- 多项目重复图片去重，前面的项目优先保留。
- 输出到 `datasets/diaper_category/<国家>/<版本>/label_studio/exports/`，后续可接 `diaper-ls-to-yolo` 和 EC2 上传训练。

## 已阅读上下文

- `makefiles/diaper-category-ec2/Makefile.mk`：已有 `diaper-ls-export`、`diaper-ls-to-yolo`、`2-diaper-workflow-after-ls` 和 EC2 上传训练命令。
- `scripts/label_studio/export_single_class_to_yolo.py`：已有单类别 LS 导出转 YOLO 逻辑，可复用其有效框判断思路。
- `web-console/server.js`：需要把新 Make 目标加入白名单和页面参数。

## 实施方案

### 1. 新增合并脚本

新增 `scripts/label_studio/merge_label_studio_exports.py`：

- 输入多个 Label Studio 导出 JSON 文件。
- 支持导出格式为任务列表，或包含 `tasks` 列表的对象。
- 对每个任务选择 latest 有效 annotation。
- 只保留包含有效 `rectanglelabels` 框的任务。
- 如果传入 `--label-name`，则只认可包含该标签的框。
- 使用 `data.local_path`、`data.image`、`meta.image_name` 或任务 `id` 作为去重 key。
- 按输入顺序去重：先导出的项目优先保留，后续重复图片跳过。
- 输出合并后的任务列表 JSON。
- 额外输出合并报告 JSON/CSV，记录每个输入文件的任务数、保留数、空标注数、重复数、最终合并数。

### 2. 新增 Make 参数与目标

在 `makefiles/diaper-category-ec2/Makefile.mk` 增加：

```makefile
LS_PROJECT_IDS ?=
DIAPER_LS_PROJECT_EXPORT_DIR ?= $(DIAPER_LS_EXPORT_DIR)/projects
DIAPER_MERGED_LS_EXPORT_PATH ?= $(DIAPER_LS_EXPORT_DIR)/merged_label_studio_export.json
DIAPER_MERGE_REPORT ?= $(DIAPER_LS_EXPORT_DIR)/merged_label_studio_export_report.json
```

新增目标：

```makefile
diaper-merge-ls-projects
```

行为：

1. 校验 `LS_PROJECT_IDS` 非空。
2. 按逗号拆分项目 ID。
3. 逐个执行 `label-studio export`，输出到 `label_studio/exports/projects/project_<id>.json`。
4. 调用 `merge_label_studio_exports.py` 合并有效任务到 `label_studio/exports/merged_label_studio_export.json`。
5. 打印后续转换命令提示。

### 3. Web 控制台

在 `web-console/server.js` 的“纸尿裤大类 / EC2”分组新增：

- `diaper-merge-ls-projects`

参数：

- `DIAPER_COUNTRY`
- `DIAPER_VERSION`
- `DIAPER_LABEL_NAME`
- `LS_PROJECT_IDS`
- `DIAPER_MERGED_LS_EXPORT_PATH`
- `DIAPER_MERGE_REPORT`

### 4. 文档与测试

更新 `README.md`、`设计.md`，新增 `tests/test_merge_label_studio_exports.py`，并执行 unittest、pylint、py_compile、Make dry-run、Node check。

## 2026-09-15 一键合并并生成 YOLO 训练集计划

### 背景

用户希望在已有 `diaper-merge-ls-projects` 的基础上，再增加一个 Make 命令：一次性完成多个 Label Studio 项目导出、有效框合并、YOLO 训练集生成。

目标用法类似：

```bash
make diaper-merge-ls-projects-to-yolo \
  DIAPER_COUNTRY=GH \
  DIAPER_VERSION=v2026-09-15 \
  DIAPER_LABEL_NAME=diaper \
  LS_PROJECT_IDS=21,20
```

### 实施方案

1. 在 `makefiles/diaper-category-ec2/Makefile.mk` 增加新目标：

```makefile
diaper-merge-ls-projects-to-yolo
```

该目标依赖或顺序执行：

```text
diaper-merge-ls-projects -> diaper-ls-to-yolo
```

并且默认通过 `DIAPER_LS_EXPORT_PATH=$(DIAPER_MERGED_LS_EXPORT_PATH)` 调用转换逻辑，避免用户再手动传合并 JSON 路径。

2. 设计转换参数：

- 复用现有 `LS_TO_YOLO_CLEAR` 与 `LS_TO_YOLO_SKIP_EMPTY`。
- 推荐用户执行时显式设置：

```bash
LS_TO_YOLO_CLEAR=1 LS_TO_YOLO_SKIP_EMPTY=1
```

- 新目标本身不强制清理，以免误删已有训练集；文档中给推荐命令。

3. Web 控制台同步：
