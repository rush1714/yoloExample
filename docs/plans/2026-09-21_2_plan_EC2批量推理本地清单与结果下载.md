# EC2 批量推理本地清单上传与结果下载计划

## 背景

在上一阶段已新增 `label-s3-ec2-predict-manifest`，支持 EC2 读取 S3/HTTP/远端本地清单批量推理并上传结果到 S3。本次用户补充三个要求：

1. 批量推理 Excel 清单在用户本地，需要先上传到 EC2 后再推理。
2. 新增命令和控制台菜单：推理完成后，先把 S3 结果记录文本下载到本地，再在本地下载推理图片、带框图、JSON、CSV 等结果，目录仍放到既定数据目录结构下。
3. 明确 EC2 端上传 S3 所需 AWS key / 权限如何配置。

## 已阅读上下文

- 上一阶段计划：`docs/plans/2026-09-21_1_plan_EC2模型S3批量推理验证.md`。
- 远端批量推理脚本：`scripts/ec2/s3_batch_predict.py`，当前支持 S3/HTTP/EC2 本地清单，输出 `summary.json`、`summary.csv`、`json/`、`annotated/` 并上传到 S3。
- EC2 编排脚本：`scripts/ec2/s3_workflow.py`，当前 `predict-s3-manifest` 负责同步远端脚本并在 EC2 执行推理命令。
- 通用 Make 路径：`makefiles/label-workflow/Makefile.mk` 当前标准数据集目录为 `datasets/<COUNTRY>/<DATA_VERSION>/<LABEL_DATASET_NAME>/`，EC2 输出目录已有 `outputs/ec2_predict/<COUNTRY>/<DATA_VERSION>/<LABEL_DATASET_NAME>/<EC2_RUN_NAME>/`。
- 控制台：`web-console/server.js` 通过 `COMMAND_GROUPS` 和 `PARAM_DEFINITIONS` 维护命令/参数白名单。

## 实现方案

### 1. 支持本地 Excel/CSV/JSON/TXT 清单自动上传到 EC2

扩展 `scripts/ec2/s3_workflow.py` 的 `predict-s3-manifest`：

1. 判断 `--predict-manifest-source`：
   - 如果是 `s3://...` 或 `http(s)://...`，保持当前行为，直接传给 EC2 脚本读取。
   - 如果是本机存在的文件路径，例如 `/Users/.../images.xlsx` 或 `./data/predict/images.xlsx`，则通过 `rsync` 上传到 EC2。
   - 如果不是 URL 且本机不存在，则按 EC2 远端路径处理，兼容已经在 EC2 上的清单。
2. 本地清单上传到远端默认路径：
   - `outputs/ec2_predict/<COUNTRY>/<DATA_VERSION>/<LABEL_DATASET_NAME>/<EC2_RUN_NAME>/manifest/<原文件名>`。
3. 新增参数：
   - `EC2_PREDICT_LOCAL_MANIFEST`：用户在控制台/Make 中填写本地 Excel/CSV/JSON/TXT 文件路径，推荐使用这个参数。
   - `EC2_PREDICT_REMOTE_MANIFEST`：上传到 EC2 后的远端路径；留空自动生成。
4. 兼容旧参数：
   - `EC2_PREDICT_MANIFEST_SOURCE` 继续可用；如果它指向本地存在文件，也会自动上传。

### 2. 推理脚本生成并上传 S3 记录文本

扩展 `scripts/ec2/s3_batch_predict.py`：

1. 在本地工作目录写入 `uploaded_s3_uris.txt`，内容为已上传到 S3 的结果文件 URI，例如：
   - `s3://bucket/prefix/summary.json`
   - `s3://bucket/prefix/summary.csv`
   - `s3://bucket/prefix/json/xxx.json`
   - `s3://bucket/prefix/annotated/xxx-annotated.jpg`
   - `s3://bucket/prefix/source_image_uris.txt`
2. 写入 `source_image_uris.txt`，记录本批次原始图片来源地址；若原始图片来源是 S3，则后续本地下载命令可以按这些 URI 下载原图。
3. 上传结果时把上述两个 txt 一起上传到 `EC2_PREDICT_OUTPUT_S3_URI`。
4. 保持不把 EC2 临时下载缓存目录 `images/` 自动上传回结果 S3，避免重复上传大图；原图下载由本地下载命令按 `summary.json` / `source_image_uris.txt` 从源地址拉取。

### 3. 新增本地下载推理结果脚本

新增 `scripts/s3/download_predict_results.py`，在本地 Mac 执行：

1. 输入：
   - `--output-s3-uri s3://bucket/prefix`：推理结果 S3 目录。
   - `--uri-list-output`：本地 S3 记录文本保存路径。
   - `--result-root`：本地结果目录，默认 `outputs/ec2_predict/<COUNTRY>/<DATA_VERSION>/<LABEL_DATASET_NAME>/<EC2_RUN_NAME>/`。
   - `--source-image-root`：本地源图片目录，默认 `datasets/<COUNTRY>/<DATA_VERSION>/<LABEL_DATASET_NAME>/predict/images/`。
   - `--download-source-images`：是否下载原始推理图片，默认启用；如只要结果可关闭。
   - `--profile`、`--region`、`--endpoint-url`：复用本地 AWS/S3 配置。
2. 执行顺序：
   - 先从 `s3://bucket/prefix/uploaded_s3_uris.txt` 下载到本地 `datasets/<...>/s3/metadata/ec2_predict_<EC2_RUN_NAME>_uploaded_s3_uris.txt`。
   - 根据这个 txt 下载 `summary.json`、`summary.csv`、`json/`、`annotated/` 到 `outputs/ec2_predict/<...>/<EC2_RUN_NAME>/`。
   - 再读取 `source_image_uris.txt` 或 `summary.json` 中的 `source` 字段，把原始推理图片下载到 `datasets/<...>/predict/images/`。
   - 写本地下载报告到 `datasets/<...>/s3/metadata/ec2_predict_<EC2_RUN_NAME>_download_report.json|csv`。

### 4. 新增 Make 命令与控制台菜单

新增通用命令：

- `label-s3-ec2-download-predict-results`：下载 S3 推理结果记录文本、结果文件和源图片到本地标准目录。

新增兼容命令：

- `brand-s3-ec2-download-predict-results`：旧 `S3_DATASET_NAME` 流程可用。

控制台新增菜单：

- 位置：`EC2 训练 / 评估 / 下载 → S3 图片数据集 → EC2`
- 新增命令：`下载 EC2 批量推理结果`
- 参数包括：
  - `EC2_PREDICT_OUTPUT_S3_URI`
  - `EC2_PREDICT_DOWNLOAD_SOURCE_IMAGES`
  - `EC2_PREDICT_LOCAL_RESULT_ROOT`
  - `EC2_PREDICT_LOCAL_SOURCE_IMAGE_ROOT`
  - `S3_PROFILE`
  - `S3_REGION`
  - `S3_ENDPOINT_URL`

同时调整现有“EC2 S3 批量推理验证”命令参数，加入 `EC2_PREDICT_LOCAL_MANIFEST`，让控制台用户直接选择/填写本地 Excel 路径，不再误以为清单必须先放到 S3。

### 5. AWS key / 权限配置说明

推荐方案：**给 EC2 绑定 IAM Role，不在 EC2 保存长期 Access Key**。

EC2 端推理脚本用 `boto3.client("s3")`，会自动走 AWS 默认凭证链。优先级包括：

1. EC2 Instance Profile / IAM Role（推荐）。
2. 环境变量：`AWS_ACCESS_KEY_ID`、`AWS_SECRET_ACCESS_KEY`、`AWS_DEFAULT_REGION`。
3. `~/.aws/credentials` 和 `~/.aws/config`。

建议给 EC2 角色最小权限：

- 输入图片/清单桶：`s3:GetObject`。
- 输出结果桶：`s3:PutObject`，必要时 `s3:AbortMultipartUpload`。
- 如果脚本后续需要列目录，再加对应 prefix 的 `s3:ListBucket`。

验证命令：

```bash
aws sts get-caller-identity
aws s3 ls s3://<bucket>/<prefix>/
```

如果短期只能使用 access key：

```bash
ssh -i /path/key.pem ec2-user@<host>
aws configure
# 或写入 ~/.aws/credentials / ~/.aws/config
```

注意：不要把 AWS access key 写进 Makefile、Git、计划文档或控制台 state；本地下载仍然使用本机 AWS profile，例如 `S3_PROFILE=smdp-yolo`。

## 预期命令示例

### 本地 Excel 清单上传到 EC2 并推理

```bash
make label-s3-ec2-predict-manifest \
  COUNTRY=GH \
  DATA_VERSION=v2026-09-20 \
  LABEL_SET=general \
  LABELS=allround_purple \
  EC2_HOST=<EC2地址> \
  EC2_KEY=/path/key.pem \
  EC2_RUN_NAME=yolo26m_img960_e100 \
  EC2_PREDICT_LOCAL_MANIFEST=/Users/guobiao/Downloads/predict_images.xlsx \
  EC2_PREDICT_INPUT_COLUMN=整改后图片URL \
  EC2_PREDICT_OUTPUT_S3_URI=s3://<bucket>/predict-results/GH/v2026-09-20/run1 \
  EC2_PREDICT_LIMIT=20 \
  EC2_EXECUTE=1
```

### 下载推理结果记录文本、结果和原图到本地

```bash
make label-s3-ec2-download-predict-results \
  COUNTRY=GH \
  DATA_VERSION=v2026-09-20 \
  LABEL_SET=general \
  LABELS=allround_purple \
  EC2_RUN_NAME=yolo26m_img960_e100 \
  EC2_PREDICT_OUTPUT_S3_URI=s3://<bucket>/predict-results/GH/v2026-09-20/run1 \
  EC2_PREDICT_DOWNLOAD_SOURCE_IMAGES=1 \
  S3_PROFILE=smdp-yolo
```
