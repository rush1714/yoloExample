# EC2 使用公共 URL 下载 S3 图片计划

## 背景

用户执行 `make 3-brand-s3-workflow-ec2-train ...` 时，`brand-s3-ec2-upload-manifest` 已成功把 labels、`ec2_image_manifest.json/csv` 和 YAML 上传到 EC2，但 `brand-s3-ec2-download-images` 在 EC2 上使用 boto3 下载 S3 图片时报错：

```text
botocore.exceptions.NoCredentialsError: Unable to locate credentials
```

用户指出当前 S3 配置里已经有公共下载地址：

```yaml
s3:
  bucket: uat-smdp4cust-bak
  region: af-south-1
  public_base_url: https://uat-smdp4cust-bak.s3.af-south-1.amazonaws.com
```

因此 EC2 应支持不依赖 AWS credentials，直接通过公共 HTTPS URL 下载图片。

## 已阅读上下文

- `scripts/ec2/s3_workflow.py`：当前 `download_images_command()` 固定在 EC2 端执行 `boto3.client("s3").download_file(...)`，所以 EC2 必须有 IAM Role 或 AWS credentials。
- `makefiles/brand-s3-ec2/Makefile.mk`：当前 EC2 下载/训练命令会传 manifest 路径，但没有下载模式参数。
- `web-console/server.js`：EC2 → S3 菜单中已有一键训练、上传 manifest、下载 S3 图片、训练入口，但没有 S3 下载模式参数。
- `tests/test_brand_s3_ec2_workflow.py`：已有 EC2 下载命令测试，可扩展覆盖公共 URL 下载逻辑。
- `scripts/label_studio/export_s3_single_class_to_yolo.py` 与 `scripts/label_studio/export_local_s3_to_yolo.py`：写入 EC2 manifest 时会保存 `source_url`；其中 `source_url` 可来自上传清单里的 `https_url`，适合公共 URL 下载。

## 核心设计

新增 EC2 图片下载模式参数：

```make
S3_EC2_DOWNLOAD_MODE ?= auto
```

支持三种模式：

- `auto`：优先使用 manifest 里的公共 URL 字段下载；没有公共 URL 时回退 boto3。
- `public`：强制使用公共 URL 下载；如果 manifest 没有可用 URL，直接报错，不尝试 boto3。
- `boto3`：保持旧逻辑，使用 `boto3.download_file()` 下载，需要 EC2 上具备 AWS credentials 或 IAM Role。

EC2 端下载优先级：

1. 从 manifest item 中读取：
   - `source_url`
   - `https_url`
   - `public_url`
2. 如果是 `http://` 或 `https://`，则用 Python 标准库 `urllib.request.urlretrieve()` 下载到目标路径。
3. 如果模式是 `auto` 且无 URL，则使用 boto3 下载。
4. 如果模式是 `public` 且无 URL，则报错提示需要重新生成带公共 URL 的 manifest，或改用 `S3_EC2_DOWNLOAD_MODE=boto3`。

## 拟实施方案

### 1. 修改 `scripts/ec2/s3_workflow.py`

- 修改 `download_images_command(args)`：
  - 注入 `args.download_mode`。
  - 远端 Python 片段增加：
    - `download_mode` 校验，只允许 `auto/public/boto3`。
    - `public_url_for_item()`：提取 `source_url` / `https_url` / `public_url`。
    - `download_public_url()`：使用 `urllib.request.urlretrieve()` 下载。
    - 只有需要 boto3 时才 import boto3；避免 public 模式仍要求 boto3 或 AWS 凭证。
- `train(args)` 内部复用 `download_images_command(args)`，因此训练前下载也自动支持公共 URL。
- `build_parser()` 新增：
  - `--download-mode`，默认 `auto`，choices 为 `auto/public/boto3`。

### 2. 修改 `makefiles/brand-s3-ec2/Makefile.mk`

- 一键命令 `3-brand-s3-workflow-ec2-train` 会通过依赖命令自动继承该参数。

### 3. 修改 `web-console/server.js`

## 预期使用方式

如果公共 URL 可访问，用户后续可以执行：

```bash
make 3-brand-s3-workflow-ec2-train \
  S3_DATASET_NAME=allround_purple \
  S3_LABEL_NAME=allround_purple \
  S3_DATASET_ROOT=datasets/allround_purple/v2026-09-17/ \
  S3_PUBLIC_BASE_URL=https://uat-smdp4cust-bak.s3.af-south-1.amazonaws.com \
  S3_EC2_DOWNLOAD_MODE=public \
  EC2_HOST=3.238.13.254 \
  EC2_USER=ec2-user \
  EC2_KEY=~/.ssh/smdp-yolo-gpu-key.pem \
  EC2_EXECUTE=1
```

这样 EC2 下载图片时会走 manifest 中的公共 HTTPS URL，不再要求 EC2 配置 AWS credentials。
