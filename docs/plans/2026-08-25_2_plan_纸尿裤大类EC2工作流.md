# 纸尿裤大类正式标注与 EC2 A10 训练流程

日期：2026-08-12

## 结论

新增了一套独立于多品牌识别的纸尿裤大类流程：

- 数据按 `datasets/diaper_category/<国家>/<版本>/` 隔离，便于不同国家和不同批次并行管理。
- Label Studio 只导入原始图片，不生成任何预标注 predictions。
- 标签固定为单类别 `纸尿裤`，YOLO class_id 固定为 `0`。
- 新增 EC2 A10 dry-run/执行脚本，覆盖上传项目、上传数据、远程训练、远程推理、下载模型。
- EC2 相关命令默认只打印 SSH/rsync 命令；传 `EC2_EXECUTE=1` 才实际执行。

## 本地流程

```bash
make diaper-workflow-to-ls \
  DIAPER_COUNTRY=ghana \
  DIAPER_VERSION=v20260812 \
  DIAPER_EXCEL=/path/to/images.xlsx \
  DIAPER_EXCEL_COLUMN=整改后图片URL

make diaper-workflow-after-ls \
  DIAPER_COUNTRY=ghana \
```

## EC2 A10 流程

建议 EC2 项目根目录：`/home/ubuntu/yoloExample`。

```bash
make diaper-ec2-upload-project EC2_HOST=<host> EC2_KEY=/path/key.pem
make diaper-ec2-upload-data EC2_HOST=<host> EC2_KEY=/path/key.pem DIAPER_COUNTRY=ghana DIAPER_VERSION=v20260812
make diaper-ec2-train EC2_HOST=<host> EC2_KEY=/path/key.pem DIAPER_COUNTRY=ghana DIAPER_VERSION=v20260812 EC2_EXECUTE=1
make diaper-ec2-predict EC2_HOST=<host> EC2_KEY=/path/key.pem DIAPER_COUNTRY=ghana DIAPER_VERSION=v20260812 EC2_PREDICT_SOURCE=/path/on/ec2/test.jpg EC2_EXECUTE=1
make diaper-ec2-download-model EC2_HOST=<host> EC2_KEY=/path/key.pem DIAPER_COUNTRY=ghana DIAPER_VERSION=v20260812 EC2_EXECUTE=1
```
