# Web 控制台加入 02-diaper-ec2-upload-data 计划

## 背景

用户希望把已有 Make 目标 `02-diaper-ec2-upload-data` 加入本地 Web 控制台，方便从页面上传本地纸尿裤 YOLO 数据集到 EC2。

现有 Makefile 中已存在：

```makefile
02-diaper-ec2-upload-data: diaper-ec2-upload-data
```

底层 `diaper-ec2-upload-data` 会上传：

- `DIAPER_DATASET_ROOT`：本地数据集目录。
- `DIAPER_DATA_YAML`：本地 YOLO YAML。
- `EC2_REMOTE_DATA_YAML`：EC2 项目内 YAML 路径。

默认仍是 dry-run，只有 `EC2_EXECUTE=1` 才会真实上传。

## 已阅读上下文

- `makefiles/diaper-category-ec2/Makefile.mk`：确认已有 `02-diaper-ec2-upload-data` 和底层 `diaper-ec2-upload-data`。
- `web-console/server.js`：当前“纸尿裤大类 / EC2”分组已有 LS 导入、合并、训练等命令，但缺少 `02-diaper-ec2-upload-data`。
- `docs/plans/2026-09-15_1_plan_多LS项目导出合并.md`：前序 Web/合并命令记录。

## 修改方案

### 1. 更新 Web 控制台命令白名单

在 `web-console/server.js` 的 `diaper_ec2` 分组中新增命令：

```text
02. 上传纸尿裤数据到 EC2
```

对应 target：

```text
02-diaper-ec2-upload-data
```

说明：

```text
上传本地纸尿裤 YOLO 数据集和 YAML 到 EC2；默认 dry-run，EC2_EXECUTE=1 才实际上传。
```

### 2. 新增/补全 Web 参数定义

命令参数列表：

- `DIAPER_COUNTRY`
- `DIAPER_VERSION`
- `DIAPER_LABEL_NAME`
- `DIAPER_DATASET_ROOT`
- `DIAPER_DATA_YAML`
- `EC2_HOST`
- `EC2_USER`
- `EC2_KEY`
- `EC2_PORT`
- `EC2_PROJECT_ROOT`
- `EC2_REMOTE_DATA_YAML`
- `EC2_EXECUTE`

如 `PARAM_DEFINITIONS` 中缺少以下参数则补充：

- `DIAPER_DATASET_ROOT`
- `DIAPER_DATA_YAML`
- `EC2_PORT`
- `EC2_PROJECT_ROOT`
- `EC2_REMOTE_DATA_YAML`

### 3. 文档同步

更新 `README.md`，在 EC2 上传数据说明中补充：

```text
Web 控制台入口：纸尿裤大类 / EC2 -> 02. 上传纸尿裤数据到 EC2
```

并给出本地数据集目录和 YAML 参数示例。

### 4. 验证

执行：

```bash
node --check web-console/server.js
```

临时启动 Web 控制台并检查 `/api/config`：

- 包含 target `02-diaper-ec2-upload-data`。
- 包含参数 `DIAPER_DATASET_ROOT`、`DIAPER_DATA_YAML`、`EC2_REMOTE_DATA_YAML`、`EC2_PORT`、`EC2_PROJECT_ROOT`。
