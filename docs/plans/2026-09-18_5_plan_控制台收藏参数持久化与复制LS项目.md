# 控制台收藏参数持久化与复制 LS 项目计划

## 背景

用户提出三项新增能力：

1. 复制一个已存在的 Label Studio 项目到新的 Label Studio 项目，并且只复制已有有效标注的任务。
2. YOLO 本地控制台增加收藏菜单功能：支持收藏末级菜单、收藏分组、收藏重命名，并持久化到本地。
3. 当前控制台参数缓存只保存在浏览器 localStorage，用户希望同步保存到本地持久化文件，重新打开页面时从本地加载，避免清浏览器缓存后参数丢失。

用户确认持久化方式使用 JSON，保存路径放到：

```text
/Users/guobiao/PRO/me/yoloExample/web-console
```

## 已阅读上下文

- `设计.md`：控制台当前说明为“参数输入会缓存到浏览器 localStorage”。需要同步更新为“浏览器 + 本地 JSON”。
- `web-console/server.js`：当前后端只提供配置、图片浏览、任务执行等 API；命令白名单与参数定义在同一文件中。
- `web-console/public/index.html`：当前前端使用 `localStorage` 保存参数，没有收藏菜单和本地状态同步 API。
- `scripts/label_studio/apply_import.py`：已有通过 Label Studio Django ORM 创建项目、任务、prediction、本地文件存储的模式。
- `scripts/label_studio/merge_label_studio_exports.py`：已有判断有效框、选择 annotation、合并多个导出文件的逻辑，可复用“有效标注”判断。
- `makefiles/common/Makefile.mk`：适合新增通用 Label Studio 项目复制命令。

## 执行方案

### 1. 新增复制已标注 LS 项目脚本

新增：

```text
scripts/label_studio/clone_annotated_project.py
```

功能：

- 在 Label Studio Django shell 中运行。
- 读取环境变量：
  - `LS_SOURCE_PROJECT_ID`：源项目 ID，必填。
  - `LS_CLONE_PROJECT_TITLE` 或 `LS_PROJECT_TITLE`：新项目标题，默认基于源项目标题追加 `Annotated Copy`。
  - `LS_CLONE_LABEL_NAME`：可选，仅复制包含该标签有效框的任务。
  - `LS_CLONE_ANNOTATION_INDEX`：`first` / `latest`，默认 `latest`。
- 从源项目读取 `label_config`、任务和 annotation。
- 只复制所选 annotation 有有效矩形框的任务。
- 复制任务 `data` / `meta`，并把所选 annotation 复制到新项目新任务。
- 如果任务使用本地文件路径，尽量为新项目创建同样的本地文件存储权限。
- 输出新项目 ID、URL、复制任务数和跳过数。

### 2. 新增 Make 命令

### 3. Web 控制台新增收藏与持久化状态 API

修改 `web-console/server.js`：

- 持久化文件路径：

```text
web-console/state.json
```

- 新增 API：
  - `GET /api/state`：读取本地 JSON 状态。
  - `PUT /api/state`：写入本地 JSON 状态。
- 状态结构：

```json
{
  "paramCache": {},
  "favorites": []
}
```

- 进行基本校验：
  - 请求大小沿用 `MAX_BODY_BYTES`。
  - `paramCache` 必须是对象。
  - `favorites` 必须是数组。
  - 每个收藏项只保存 `id`、`group`、`title`、`target`、`params`。
  - `target` 必须在现有 Make 白名单中。
- 使用临时文件 + rename 原子写入。

### 4. Web 前端参数缓存改为浏览器 + 本地 JSON 双写

修改 `web-console/public/index.html`：

- 初始化时：
  - 先读取 `/api/state`。
  - 将服务端 `paramCache` 与浏览器 localStorage 合并，服务端优先或浏览器非空覆盖服务端（实现中需选定一个稳定策略）。
  - 再同步写回 localStorage 和服务端。
- 参数变更时：
  - 更新 `state.paramCache`。
  - 写 localStorage。
  - 防抖 `PUT /api/state`。
- 清空参数缓存时：
  - 清 localStorage。
  - 清服务端 `paramCache`。

### 5. Web 前端新增收藏菜单

修改 `web-console/public/index.html`：

- 左侧增加“收藏菜单”。
- 每个命令详情页增加：
  - `收藏命令` 按钮。
  - 如果当前显示的是收藏项，增加 `重命名收藏`、`删除收藏`。
- 收藏时通过 `prompt()` 简化输入：
  - 收藏分组，默认 `默认`。
  - 收藏名称，默认当前命令标题。
- 收藏项保存：

```json
{
  "id": "fav_...",
  "group": "S3训练",
  "title": "一键训练 allround",
  "target": "3-brand-s3-workflow-ec2-train",
  "params": {
    "S3_DATASET_NAME": "allround_purple"
  }
}
```

- 点击收藏项：
  - 打开原命令详情页。
  - 将收藏保存的 params 应用到当前表单和参数缓存。

## 预期结果

- 用户可在控制台复制已有 Label Studio 项目，仅复制带有效标注的任务。
- 用户可收藏常用末级命令，支持分组、重命名、删除，并持久化到 `web-console/state.json`。
- 控制台参数不再只依赖浏览器缓存，本地 JSON 会保存一份，重新打开页面可恢复参数。
- `LS_PROJECT_ID=21,20` 可用于多项目合并导出和生成 YOLO / S3 EC2 清单。
