## 核心业务与技术结论

1. **技术指标完全达标**：
   - 加纳（GH）真实复杂货架 350 张图片实测取得 **96.10% Precision** 与 **90.51% mAP@50**，误检率低，达到商业化验收标准。
2. **终端实时扫码唯一解**：
   - 手机端直接打开相机实时画框计数（30 FPS），必须采用 YOLO（已成功导出 iOS CoreML 与 Android ONNX/NCNN），单次推理仅需 20~50ms，**服务器算力开销为 0 元**，100% 离线可用。
3. **多模态大模型 API 价格梯度与 ROI**：
   - 即便采用全球价格最激进的 DeepSeek 多模态 API，在 2 万张/天与 10 万张/天规模下，自研 YOLO 端侧方案仍可每年节省 **2.16 万元 至 270.0 万元** 纯 API 开销。
4. **端云协同二段式最佳架构**：
   - **前端/端侧**：轻量 YOLO 现场秒级识别、精准计数与防抖质检。
   - **后端/云端**：多模态大模型 + 规则引擎进行多维门店画像、陈列合规评分与 CRM 2.0 经营建议。
