# 2026-09-22 Plan 1: 模型移动端与通用格式导出脚本及 Web 控制台菜单集成

## 1. 目标与背景

用户已使用 YOLO（如 `yolo26s`）训练了检测模型，需要将其导出为移动端或离线推理可用的格式（如 iOS CoreML、Android TFLite、NCNN、ONNX 等），以便在手机端调用摄像头进行实时推理或进行端侧部署。

本次任务需要：
1. 编写一个通用的模型导出脚本 `scripts/export/export_model.py`，支持自定义模型权重路径、目标导出格式、分辨率、NMS 算子集成、半精度（FP16）、INT8 量化以及输出目录等参数。
2. 在 Makefile 中新增对应的导出命令及参数定义（如 `make export-model` 或 `make model-export`）。
3. 在本地 Web 控制台（`web-console`）中将该导出命令加入命令白名单并在左侧菜单/页面中增加可视化操作界面，支持自定义输入参数并实时执行。
4. 符合项目开发规范：代码带详细注释，遵循架构设计，并通过 `pylint` 检查。

## 2. 详细设计与改动清单

### (1) 导出脚本：`scripts/export/export_model.py`
- **支持参数**：
  - `--model` / `-m`：模型权重路径（默认 `models/train/multibrand/weights/best.pt` 或 `models/yolo26s.pt`，支持任意绝对/相对路径）。
  - `--format` / `-f`：目标导出格式，支持 `coreml`、`tflite`、`ncnn`、`onnx`、`openvino`、`torchscript`、`engine`（TensorRT）等（默认 `onnx`）。
  - `--imgsz`：输入分辨率（默认 `640`，支持单值或 `H,W`）。
  - `--half`：是否启用 FP16 半精度导出（默认针对支持的格式如 CoreML 推荐开启）。
  - `--int8`：是否启用 INT8 量化（配合 `--data` 可传入校准数据集 YAML）。
  - `--nms`：是否集成 NMS 算子（对 CoreML/ONNX/TFLite 打包后处理，极大幅度简化端侧解析）。
  - `--device`：导出设备（`cpu`、`mps`、`cuda`、`0` 等，默认 `cpu`）。
  - `--output-dir`：导出产物目标目录（可选，若指定则将导出产生的文件/目录自动移动或归档至目标路径，默认保留在原权重同级或 Ultralytics 导出路径）。
  - `--simplify`：ONNX 是否进行 simplify 优化。
- **功能特性**：
  - 导出前后校验权重文件是否存在。
  - 自动打印导出结果路径及对应平台（iOS / Android / 跨平台）的使用提示。
  - 完整的错误捕获与日志输出。

### (2) Makefile 模块与命令定义
- 在 `makefiles/common/Makefile.mk`（或新建 `makefiles/export/Makefile.mk` 并在根 `Makefile` 引入）新增目标：
  - 命令：`export-model`
  - 变量支持：
    - `EXPORT_MODEL_PATH`（默认 `models/train/multibrand/weights/best.pt`）
    - `EXPORT_FORMAT`（默认 `onnx`，可选 `coreml,tflite,ncnn,onnx,engine` 等）
    - `EXPORT_IMGSZ`（默认 `640`）
    - `EXPORT_HALF`（默认 `0` 或 `1`）
    - `EXPORT_INT8`（默认 `0`）
    - `EXPORT_NMS`（默认 `1`）
    - `EXPORT_DEVICE`（默认 `cpu`）
    - `EXPORT_OUTPUT_DIR`（可选）
- 在 `make help` 和 `make help-params` 中同步补充参数说明。

### (3) Web 控制台集成
- **后端（`web-console/server.js`）**：
  - 在 `COMMAND_WHITELIST` 中加入 `export-model`。
- **前端（`web-console/public/index.html`）**：
  - 在左侧菜单导航树中增加一级或二级分组（例如在“本地 Mac 训练 / 推理”下增加“模型格式导出 / 移动端导出”，或者单独的“模型导出 / 部署”菜单项）。
  - 页面提供直观的表单控件：
    - 模型权重文件路径（输入框 + 快捷提示）
    - 导出格式（下拉框：CoreML(iOS)、TFLite(Android)、NCNN(移动端极速)、ONNX(通用) 等）
    - 图像尺寸 `imgsz`（数字输入框）
    - 启用半精度 FP16（切换开关 / 勾选框）
    - 集成 NMS 后处理（切换开关 / 勾选框）
    - 目标设备 / 输出路径等
  - 实时命令预览与一键执行、日志输出。

### (4) 静态检查与测试验证

- 测试常见导出场景（如导出 ONNX / CoreML），验证 Web 控制台与 Makefile 运行正常。
