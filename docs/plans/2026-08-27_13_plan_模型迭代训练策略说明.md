# 模型迭代训练策略说明

## 1. 总体原则

模型迭代时，不建议每次都无限循环使用上一轮 `best.pt` 继续训练，也不建议每来一批数据就完全无对照地重新训练。

更常见、也更稳妥的做法是按阶段区分：

```text
首版模型：官方预训练模型 + 当前全量数据
日常新增数据：上一版 best.pt + 新旧全量数据
重要版本：官方预训练模型和上一版 best.pt 都跑一遍，比较后选择更好的
```

## 2. 首版模型怎么训练

首版模型建议从官方预训练模型开始，例如：

```text
base = yolo11s.pt 或 yolo11m.pt
data = 当前已经确认可用的全部标注数据
```

对于当前纸尿裤大类任务，推荐流程是：

```text
smoke:    yolo11n.pt + CI 数据，imgsz=640，epochs=5
baseline: yolo11s.pt + CI 数据，imgsz=960，epochs=100
improve:  yolo11m.pt + CI 数据，imgsz=960，epochs=150
```

首版阶段的目标是：

1. 验证训练链路是否通；
2. 验证数据集格式是否正确；
3. 建立第一个可比较的 baseline；
4. 判断更大模型是否值得作为主力模型。

## 3. 日常新增数据怎么训练

如果后续新增的是同一业务、同一类别、相似国家或相似货架场景的数据，例如：

```text
CI_v1 -> CI_v2
```

更常见的做法是使用上一版模型继续微调：

```text
base = 上一版 best.pt
data = 旧数据 + 新数据
epochs = 50~100
```

不要只用新数据训练，否则模型可能遗忘旧场景。

推荐：

```text
上一版 best.pt + 旧数据 + 新数据 -> 新版本 best.pt
```

## 4. 重要版本怎么训练

如果是一次重要版本，例如：

- 新增大量数据；
- 新增国家；
- 新增明显不同的门店或陈列风格；
- 模型要进入更正式的业务验证；

建议至少跑两组对照：

```text
A: 官方 yolo11m.pt + 全量数据
B: 上一版 best.pt + 全量数据
```

然后比较：

```text
Precision
Recall
mAP50
mAP50-95
图片级可用率
推理速度
误检/漏检样例
```

哪个效果更好，就选哪个作为新版本模型。

## 5. 新国家数据怎么处理

如果新数据来自不同国家，且包装、货架、光照、门店环境差异明显，不建议盲目相信旧模型。

推荐优先跑：

```text
官方 yolo11m.pt + 旧国家数据 + 新国家数据
```

如果时间和资源允许，再跑对照：

```text
上一版 best.pt + 旧国家数据 + 新国家数据
```

原因：

- 旧模型可能已经学到纸尿裤货架的通用特征；
- 但旧模型也可能对某个国家或某些包装风格产生偏见；
- 用官方模型重新训练可以作为更干净的对照组。

## 6. 什么时候可以用 best.pt 继续训练

可以用上一版 `best.pt` 作为基座的情况：

1. 新数据量不大，例如 100~1000 张；
2. 新旧数据场景相似；
3. 仍然是同一个任务和同一个类别体系；
4. 希望快速收敛；
5. 会把旧数据和新数据混在一起训练。

推荐形式：

```text
base = old_best.pt
data = old_data + new_data
epochs = 50~100
```

## 7. 什么时候不建议一直 best.pt 接 best.pt

不建议这样无限循环：

```text
best_v1.pt -> best_v2.pt -> best_v3.pt -> best_v4.pt
```

如果每次都是同一批数据，反复用上一轮 `best.pt` 继续训练，风险是：

1. 过拟合同一批数据；
2. 实验不可比较；
3. 不知道提升来自模型、数据、epoch 还是训练起点；
4. 可能对新国家或新场景泛化变差。

因此，重要版本必须保留官方预训练模型作为对照。

## 8. 当前项目建议流程

### 当前 CI 首版

```text
smoke:    yolo11n.pt + CI/v2026-08-27_01
baseline: yolo11s.pt + CI/v2026-08-27_01
improve:  yolo11m.pt + CI/v2026-08-27_01
```

选择表现最好的模型作为：

```text
diaper_ci_v1_best.pt
```

### 下一批 CI 数据

如果下一批仍是 CI 数据，例如：

```text
CI/v2026-09-10_01
```

推荐：

```text
base = diaper_ci_v1_best.pt
data = CI_v1 + CI_v2
epochs = 50~100
```

如果这是重要版本，再跑一个对照：

```text
base = yolo11m.pt
data = CI_v1 + CI_v2
epochs = 100~150
```

### 新国家数据

如果新增国家，例如：

```text
GH/v2026-09-10_01
```

推荐：

```text
实验 A：yolo11m.pt + CI + GH
实验 B：diaper_ci_v1_best.pt + CI + GH
```

比较后选择更好的模型作为多国家版本。

## 9. 简化决策表

| 场景 | 推荐基座 | 训练数据 | 说明 |
|---|---|---|---|
| 首版模型 | 官方 `yolo11s.pt` / `yolo11m.pt` | 当前全量数据 | 建立干净 baseline |
| 同国家少量新增数据 | 上一版 `best.pt` | 旧数据 + 新数据 | 快速微调，避免遗忘 |
| 新国家/新场景 | 官方 `yolo11m.pt` 优先 | 旧数据 + 新国家数据 | 防止旧模型偏见 |
| 重要版本发布 | 官方模型和上一版 best 都跑 | 全量数据 | 对照后选择更优模型 |
| 训练中断恢复 | `last.pt` | 原训练数据 | 这是 resume，不是新实验 |

## 10. 最终建议

当前阶段不要纠结每次都从哪里开始。建议采用简单规则：

```text
首版：官方预训练模型 + 当前全量数据
日常迭代：上一版 best.pt + 新旧全量数据
重要版本：官方预训练模型 vs 上一版 best.pt，两者都跑，谁好用谁
```

对于当前 CI 纸尿裤大类任务：

1. 先完成 `yolo11m.pt` improve；
2. 对比 smoke / baseline / improve；
3. 选出当前最佳模型作为 `diaper_ci_v1_best.pt`；
4. 后续新增 CI 数据时，默认用该 best.pt 加旧数据和新数据一起微调；
5. 新国家或重要发布时，再用官方 yolo11m.pt 做对照训练。
