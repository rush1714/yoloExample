# 批量推理结果下载进度与超时优化计划

## 背景

用户执行：

```bash
make label-s3-ec2-download-predict-results \
  COUNTRY=GH \
  DATA_VERSION=v2026-09-20 \
  LABEL_SET=general \
  LABELS=kleesoft_purple,allround_purple \
  EC2_RUN_NAME=yolo26m_img960_e100 \
  EC2_PREDICT_OUTPUT_S3_URI=s3://uat-smdp4cust-bak/yolo-training/predict-results/ \
  EC2_PREDICT_DOWNLOAD_SOURCE_IMAGES=1 \
  S3_PROFILE=smdp-yolo \
  S3_REGION=af-south-1
```

后感觉“没反应”。上一轮曾建议补充进度日志和 HTTP 下载 timeout，但实际尚未实现。本次需要补齐该体验优化。

## 已阅读上下文

- `scripts/s3/download_predict_results.py`：当前本地下载脚本会下载 `uploaded_s3_uris.txt`、结果文件和可选原始图片，但下载过程中几乎不打印进度；HTTP 图片下载使用 `urlretrieve`，没有显式 timeout。
- `makefiles/ec2/Makefile.mk`：已有 `EC2_PREDICT_DOWNLOAD_SOURCE_IMAGES`、本地结果目录和本地原图目录参数，但没有 `EC2_PREDICT_SOURCE_DOWNLOAD_TIMEOUT`。
- `makefiles/label-workflow/Makefile.mk`：`label-s3-ec2-download-predict-results` 当前调用下载脚本，但没有传 timeout 参数。
- `makefiles/brand-s3-ec2/Makefile.mk`：兼容下载命令同样没有传 timeout 参数。
- `web-console/server.js`：控制台已有下载结果命令，但参数列表和参数定义中没有下载 timeout。

## 实现方案

### 1. 下载脚本增加可见进度日志

修改 `scripts/s3/download_predict_results.py`：

1. 下载 `uploaded_s3_uris.txt` 前打印：
   ```text
   download uri list s3://... -> 本地路径
   ```
2. 读取 URI 数量后打印：
   ```text
   result files to download: N
   ```
3. 每下载一个结果文件打印：
   ```text
   download result file 12/760 s3://... -> 本地路径
   ```
4. 若结果文件下载失败，立即打印失败信息，但继续处理后续文件。
5. 下载原图前打印：
   ```text
   source images to download: 379
   ```
6. 每下载一张原图打印：
   ```text
   download source image 12/379 https://... -> 本地路径
   ```
7. 若 `EC2_PREDICT_DOWNLOAD_SOURCE_IMAGES=0`，打印明确提示：
   ```text
   skip source images download
   ```
8. 所有进度日志使用 `flush=True`，保证 Web 控制台和终端实时显示。

### 2. HTTP 原图下载增加 timeout

修改 `scripts/s3/download_predict_results.py`：

1. 不再用无 timeout 的 `urlretrieve` 下载 HTTP 图片。
2. 改用：
   ```python
   urlopen(source_url, timeout=timeout)
   ```
   并用 `shutil.copyfileobj` 写入本地文件。
3. 新增 CLI 参数：
   ```bash
   --source-download-timeout 30
   ```
4. 仅用于 HTTP(S) 原图下载；S3 下载仍使用 boto3 的 `download_file`。

### 3. Make 参数透传

修改 `makefiles/ec2/Makefile.mk`：

- 新增：
  ```make
  EC2_PREDICT_SOURCE_DOWNLOAD_TIMEOUT ?= 30
  ```
- `ec2-print-params` 增加该参数展示。

修改 `makefiles/label-workflow/Makefile.mk`：

- `label-s3-ec2-download-predict-results` 追加：
  ```bash
  --source-download-timeout $(EC2_PREDICT_SOURCE_DOWNLOAD_TIMEOUT)
  ```

修改 `makefiles/brand-s3-ec2/Makefile.mk`：

- `brand-s3-ec2-download-predict-results` 同样追加 timeout 参数。

### 4. 控制台参数补充

修改 `web-console/server.js`：

1. `PARAM_DEFINITIONS` 新增：
   ```text
   EC2_PREDICT_SOURCE_DOWNLOAD_TIMEOUT
   ```
   默认值 `30`，类型 `number`。
2. “下载 EC2 批量推理结果”命令参数列表加入该参数。
