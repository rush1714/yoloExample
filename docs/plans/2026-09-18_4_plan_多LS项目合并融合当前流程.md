# 多 LS 项目合并融合当前流程计划

## 背景

用户反馈 Web 控制台中原有两个命令不见了：

- `diaper-merge-ls-projects`
- `diaper-merge-ls-projects-to-yolo`

同时用户希望：`LS_PROJECT_ID` 参数支持多个项目 ID，一次导出多个 Label Studio 项目并生成 YOLO 训练集。结合当前正在使用的流程，还需要支持“本地地址 LS 项目合并后，匹配 S3 上传清单，生成 EC2 从 S3 下载训练所需的 manifest”。

## 已确认现状

- `makefiles/diaper-category-ec2/Makefile.mk` 中仍存在：
  - `diaper-merge-ls-projects`
  - `diaper-merge-ls-projects-to-yolo`
- `scripts/label_studio/merge_label_studio_exports.py` 已支持多个 Label Studio 导出 JSON 合并，只保留有有效框的任务并去重。
- `web-console/server.js` 当前没有把这两个 `diaper-*` 合并命令放回控制台菜单。
- 现有 `diaper-*` 合并命令使用 `LS_PROJECT_IDS`，用户希望也能用 `LS_PROJECT_ID=21,20` 这种形式。
- 当前 S3 EC2 兼容路径已有：
  - `local-ls-s3-to-yolo`
  - `2-local-ls-s3-workflow-after-ls`
  但还没有“多个 LS 项目导出合并后再匹配 S3 manifest”的一键命令。

## 执行方案

### 1. 恢复控制台中的纸尿裤多项目合并命令

修改 `web-console/server.js`，在 “Label Studio → 导入 / 导出 / 转 YOLO” 中加入：

- `diaper-merge-ls-projects`：合并多个 LS 项目有效标注。
- `diaper-merge-ls-projects-to-yolo`：合并多个 LS 项目并生成 YOLO。

控制台参数使用 `LS_PROJECT_ID`，说明支持英文逗号分隔多个项目 ID，例如 `21,20`。

### 2. 让 `LS_PROJECT_ID` 支持多个项目

修改 `makefiles/diaper-category-ec2/Makefile.mk`：

- 将 `LS_PROJECT_IDS` 默认值改成兼容 `LS_PROJECT_ID`：
  - `LS_PROJECT_IDS ?= $(LS_PROJECT_ID)`
- 保留 `LS_PROJECT_IDS`，已有命令不破坏；用户也可以继续显式传 `LS_PROJECT_IDS=21,20`。

### 3. 新增本地 LS 多项目合并后匹配 S3 的命令

修改 `makefiles/brand-s3-ec2/Makefile.mk`，新增：

- `local-ls-s3-merge-projects`：
  - 根据 `LS_PROJECT_ID` / `LS_PROJECT_IDS` 导出多个本地地址 LS 项目；
  - 调用 `merge_label_studio_exports.py` 合并有有效框任务；
  - 输出到 `LOCAL_LS_EXPORT_PATH` 或专用合并路径。
- `2-local-ls-s3-merge-workflow-after-ls`：
  - 执行 `local-ls-s3-merge-projects`；
  - 再执行 `local-ls-s3-to-yolo`；
  - 生成 YOLO labels、`ec2_image_manifest.json/csv` 和 S3 YAML。

### 4. 控制台新增当前流程的一键入口

在 `web-console/server.js` 的 “图片来源 / 标注准备 → 本地目录 → S3 → LS” 中加入：

- `local-ls-s3-merge-projects`
- `2-local-ls-s3-merge-workflow-after-ls`

用于当前“LS 本地地址 + 多项目 + S3 下载训练”流程。

### 5. 文档与架构同步

更新：

- `makefiles/brand-s3-ec2/README.md`
- `makefiles/diaper-category-ec2/README.md`
- `设计.md`

说明 `LS_PROJECT_ID` 支持多个 ID，以及本地 LS 多项目合并后生成 S3 EC2 训练清单的用法。

### 6. 测试与验证

更新 `tests/test_brand_s3_ec2_workflow.py`，覆盖：

- Makefile 中存在新增多项目命令。
- 控制台白名单包含新增 target。
- `LS_PROJECT_IDS ?= $(LS_PROJECT_ID)` 兼容关系存在。

执行：

- `uv run python -m unittest discover -s tests -p 'test_brand_s3_ec2_workflow.py'`
- `uv run pylint scripts/label_studio/export_local_s3_to_yolo.py scripts/ec2/s3_workflow.py tests/test_brand_s3_ec2_workflow.py`
- `node --check web-console/server.js`
- `make -n 2-local-ls-s3-merge-workflow-after-ls ...` 预览命令展开。

## 预期结果

- 控制台重新出现 `diaper-merge-ls-projects` 和 `diaper-merge-ls-projects-to-yolo`。

- 当前本地 LS 地址流程可一次合并多个项目，匹配 `s3_images.json`，生成 EC2 从 S3 下载训练所需的 `ec2_image_manifest.json/csv`。
