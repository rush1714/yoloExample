# 纸尿裤大类模型指标合格标准与当前结论

## 1. 不同使用场景的合格线

| 使用场景 | Precision | Recall | mAP50 | mAP50-95 | 结论 |
|---|---:|---:|---:|---:|---|
| 辅助人工标注 | ≥ 0.60 | ≥ 0.65 | ≥ 0.65 | ≥ 0.30 | 可用于减少人工画框工作量 |
| 内部业务粗略分析 | ≥ 0.75 | ≥ 0.75 | ≥ 0.75 | ≥ 0.40 | 可用于初步统计和趋势判断 |
| 自动化生产 / 少人工复核 | ≥ 0.85 | ≥ 0.85 | ≥ 0.85 | ≥ 0.55 | 可用于更稳定自动化判断 |
| 严格生产标准 | ≥ 0.90 | ≥ 0.90 | ≥ 0.90 | ≥ 0.60 | 高可信自动化应用 |

## 5. 下一阶段建议目标

如果要进入更稳定的业务使用阶段，建议目标设为：

```text
Precision ≥ 0.78
Recall    ≥ 0.80
mAP50     ≥ 0.80
mAP50-95  ≥ 0.45
```

解释：

- `Recall` 要尽量高，因为漏检会导致少算陈列面、少算商品数量；
- `mAP50-95` 要继续提升，因为它反映框的位置是否精准；
- 如果 mAP50 高但 mAP50-95 低，说明模型大概能找到目标，但框得还不够准。

## 6. Improve 阶段是否值得保留的判断标准

当前 improve 使用：

```text
模型：yolo11m.pt
imgsz：960
epochs：150
```

它至少应超过 baseline：

```text
Recall    > 0.76
mAP50     > 0.78
mAP50-95  > 0.40
```

如果最终达到：

```text
Precision ≥ 0.78
Recall    ≥ 0.78~0.80
mAP50     ≥ 0.80
mAP50-95  ≥ 0.42~0.45
```

则可以认为：

```text
yolo11m 值得作为下一版主力模型。
```

如果只是小幅提升，例如：

```text
mAP50     0.749 → 0.760
mAP50-95  0.373 → 0.380
```

则说明：

```text
模型变大收益有限，更应该优先优化数据质量、标注规范和业务样本覆盖。
```

## 7. 除 mAP 外建议增加的业务指标

建议增加一个更贴近业务的指标：

```text
图片级可用率
```

例如随机抽 100 张图片：

| 图片级可用率 | 判断 |
|---:|---|
| ≥ 80% | 可扩大数据和业务验证 |
| 70%～80% | 可用于辅助，但仍需人工修正 |
| < 70% | 模型或标注规范仍需调整 |

图片级可用的定义可以是：

```text
主要纸尿裤陈列区域基本被识别，误检和漏检不影响人工快速判断。
```

## 8. 最终结论

当前 baseline 已经证明：

```text
模型能学到纸尿裤目标；
训练链路是通的；
当前数据集具备可训练性；
PoC 阶段合格。
```

但如果要进一步用于稳定业务分析或更少人工复核，下一阶段目标应提升到：

```text
mAP50     ≥ 0.80
Recall    ≥ 0.80
mAP50-95  ≥ 0.45
```

当前最合理的下一步是：

```text
继续完成 yolo11m improve 训练；
对比 improve 与 baseline；
如果提升明显，保留 yolo11m；
如果提升不明显，优先优化数据和标注规范。
```
